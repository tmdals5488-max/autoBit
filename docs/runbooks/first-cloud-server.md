# 첫 상시 모의매매 서버 준비

2026-10-16 사용자는 Mac을 꺼도 동작하는 서버 준비를 선택했다. 아직 클라우드 계정·예산은 확인 중이며 서버 생성, 과금, 배포, 상시 실행은 하지 않았다.

## 구성 후보

기존 배포 코드와 호환되는 OCI Ubuntu 22.04 ARM64, VM.Standard.A1.Flex 1 OCPU / RAM 6 GB / 부팅 디스크 50 GB 한 대를 우선 검토한다. 계정 홈 리전의 실제 이미지·수용량·남은 무료 할당량과 생성 화면의 비용을 확인한 뒤 확정한다. 무료 수용량이 없다고 유료 사양으로 자동 변경하지 않는다.

[공식 무료 자원 안내](https://docs.oracle.com/en-us/iaas/Content/FreeTier/freetier_topic-Always_Free_Resources.htm)의 확인 시점 기준 A1 무료 한도는 월 1,500 OCPU 시간 및 9,000 GB 시간이며, 블록 스토리지 합계 200 GB다. 다른 자원의 사용량도 합산된다. 사용량이 적은 무료 인스턴스는 회수될 수 있으므로 상시 가용성을 보장하지 않는다. 인위적인 부하는 만들지 않는다.

## 배포 전 해소할 항목

- 사용자 계정 로그인과 무료/유료 예산 선택. 가입·본인 인증·결제 정보 입력은 사용자가 직접 처리하며 비밀번호나 인증 코드를 대화로 받지 않는다.
- 현재 Mac에는 PowerShell이 없다. 기존 검증된 배포 래퍼를 실행할 환경을 준비하거나 동등한 계약을 검증한 대체 도구가 필요하다.
- 기존 서비스·활성화 검사·프로세스 검사는 Telegram 설정을 필수로 요구한다. 새 설치에서 알림을 사용할지 결정하고, 미사용 시에는 이 세 경계를 함께 수정하고 검증해야 한다. 가짜 인증 파일로 통과시키지 않는다.
- 배포 래퍼는 정확한 원격 main 커밋만 받는다. 로컬 연구 브랜치를 그대로 배포하지 않는다. 배포할 변경의 검토·원격 반영을 먼저 완료한다.
- Linux 배포 검사를 대상 운영체제에서 실행한다. macOS에서 확인된 기존 GNU/Linux 의존 테스트 실패를 배포 성공으로 취급하지 않는다.

## 최초 설치 및 완료 기준

1. 서버와 접속 키를 만들고 SSH는 운영자 접속 주소로 제한한다. 봇을 위한 외부 수신 포트는 열지 않는다. 키 원문은 저장소나 대화에 넣지 않는다.
2. SSH 호스트 키를 확인하고 기존 Prepare로 고정 런타임·의존성·분리된 모의 원장을 검증한다.
3. 검증한 paper-only 서비스를 설치하고 자동 시작과 재시작 설정을 확인한다. 업비트 계정 키는 필요하지 않다.
4. 서버에서 새로운 모의 원장을 시작한다. Mac에서 1회 실행한 원장은 그대로 보존하고 기간·손익을 합산하지 않는다.
5. active 단일 프로세스, KRW-BTC / normalized-paper, 최신 확정봉, 원장 무결성, 공개 시세 접근과 다음 예정 처리를 확인한다.
6. 후속 캔들이 실제 처리되고 기록이 이어지는 것을 확인한다. 별도 저장소 백업은 대상·비용을 정한 뒤 복구 검증까지 수행한다. 같은 디스크의 백업만으로 서버 손실 복구가 가능하다고 보고하지 않는다.

서버 준비 완료와 수익성 검증 완료는 별개다. 현재는 모의 운용 기록을 쌓는 단계이며 실거래 잠금은 유지한다. 서비스 설치의 세부 절차는 [기존 OCI runbook](oci-paper.md)을 따른다.
